# 🎮 Maze Adventure

A browser-based 2D maze game built using **HTML, CSS, and JavaScript**.

Navigate through challenging mazes, collect coins, find the key, avoid enemies, and reach the exit before time runs out!

## 🎮 Play the Game

👉 **[Play Maze Adventure →](https://raigiriviplav.github.io/2D-Maze-Game/)**

## ✨ Features

- 🎯 3 playable levels
- 🔑 Key and exit system
- 🪙 Coin collection
- 👾 Moving enemy
- ❤️ 3 lives
- ⏱️ Countdown timer
- 🏆 Score and high-score system
- 💾 High score saved using Local Storage
- ⏸️ Pause and restart functionality
- 🔊 JavaScript-generated sound effects
- 📱 Mobile-friendly controls
- ⌨️ Keyboard controls

## 🕹️ Controls

### Desktop

- **W / A / S / D** → Move
- **Arrow Keys** → Move
- **P** → Pause / Resume

### Mobile

Use the on-screen directional buttons to move.

## 🎯 How to Play

1. Click **Start Game**.
2. Navigate through the maze.
3. Collect 🪙 coins to increase your score.
4. Find the 🔑 key.
5. Avoid the moving 👾 enemy.
6. Reach the 🚪 exit after collecting the key.
7. Complete all 3 levels to win.

## 🛠️ Technologies Used

- **HTML5** – Game structure
- **CSS3** – Styling and responsive interface
- **JavaScript** – Game logic and interactions
- **DOM Manipulation** – Dynamic game updates
- **Local Storage** – Persistent high scores
- **setInterval()** – Timer and enemy updates
